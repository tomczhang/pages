mdsite 项目介绍

2026-06-19

mdsite —— 把 Markdown 一键变成你自己的在线报告站

一条命令，把一段 Markdown / 对话内容变成云端可分享的精美 HTML 页面，部署到你自己的 GitHub Pages。

Why · 为什么做它

日常最高频的一个需求：把对话里的分析结论、设计方案、周报随手变成一个好看、能直接发链接的页面。现有内部方案绑死在内网基建上、无法对外用，也有 IP 包袱。

mdsite 用 clean-room 重写了这套能力，把基建换成每个人自己的 GitHub：

  • 不用搭服务器、不用配 CI——push 到 GitHub Pages 即自动上线。
  • 维护者不托管任何内容——你发布的东西只在你自己的 GitHub 账号下，所以这是个「工具」而非「平台」。

Try it · 试一下

# 1) 初始化（在你自己的 GitHub 建/复用一个 pages 仓库 + 开 Pages）
mdsite init

# 2) 把一篇 Markdown 变成在线报告
mdsite publish notes.md --title "我的周报" --category report --summary "本周进展"
# → 输出真实链接：https://<你>.github.io/<repo>/report/<日期>/<slug>.html

站点根 https://<你>.github.io/<repo>/ 就是你所有报告的时间轴首页，超过 30 天的会自动折叠。

Install · 安装

npm i -g mdsite      # 或 npx mdsite <command>
mdsite --help

认证只需一次，不用 SSH key、不用配 GitHub Action，推荐最小权限：

  1. gh auth login（首选，token 不落任何文件）
  2. fine-grained PAT，只授权那一个 pages 仓库（Contents + Pages + Administration: write）
  3. classic repo PAT（兜底，注意它授予全部仓库读写）

Features · 特性

  • md / html 双输入：Markdown 自动转 HTML，或直通你已产出的精装 HTML。
  • 单文件自包含：产物就一个 .html，Tailwind + Alpine 走公网 CDN，天生好分享。
  • 时间轴首页：报告倒序排列，超 30 天自动折叠——折叠在浏览时按当前日期算，不会固化。
  • 多设备安全合并：多台机器并发发布，索引 pages.json 自动语义合并、不丢条目。
  • 凭证不落盘：GitHub token 只经子进程环境临时注入，绝不写进 .git/config 或日志。
  • 覆盖保护：不会误覆盖你已有的 Pages 站点；也不会动你已有仓库的 main 分支。
  • 双层模板：内置模板可被 ~/.mdsite/templates/ 覆盖自定义。

Privacy · 隐私

你的内容只属于你。

  • 所有页面只部署到你自己配置的 GitHub 仓库，由你自己的 GitHub Pages 对外服务，用的是你自己的凭证。
  • 工具不向任何维护者运营的后端发请求，维护者不托管、不缓存、不聚合任何用户内容。
  • 首页索引只列你本人站点里的报告，不存在任何跨用户的汇总入口或中心服务。
  • 因此 mdsite 是「工具作者」立场（类似 Hugo / Jekyll），不是「平台方」。
