mdsite 使用指南

2026-06-21

安装、认证、发布流程与文档模板形态的一站式说明

目录

把一段 Markdown / 对话内容一键变成云端可分享的精美 HTML 报告，发布到你自己的 GitHub Pages。BYO-host：内容只部署到你自己的 repo，用你自己的凭证。

安装

npm i -g @tomczhang/mdsite     # 或从源码 npm link
mdsite --help

认证（只需一次）

gh auth login                  # 推荐，token 不落盘
# 或 export GITHUB_TOKEN=github_pat_…（fine-grained，最小权限）

核心流程

mdsite init                                                  # 建/复用 repo + 开 gh-pages Pages
mdsite publish notes.md --title "周报" --category report --summary "本周进展"
# → https://<你>.github.io/<repo>/report/<日期>/<slug>.html
  • .md 转 HTML 正文；.html 直通。
  • --template：report（默认）/ doc（三栏导航）/ dashboard。
  • 站点根是全部报告的倒序时间轴，超 30 天自动折叠。

辅助命令

mdsite doctor          # 体检：凭证 / 工作区 / 配置
mdsite serve           # 本地预览
mdsite template list   # 查看可用模板
mdsite template eject report   # 拷内置模板到 ~/.mdsite/templates/ 自定义
