mdsite 使用指南

把一段 Markdown / 对话内容一键变成云端可分享的精美 HTML 报告，发布到你自己的 GitHub Pages。

BYO-host：内容只部署到你自己的 GitHub repo + Pages，用你自己的凭证。我们不托管任何内容。

这是什么

mdsite = skill + CLI（Node ≥ 20）。它做三件事：

  1. 把 Markdown 或现成 HTML 灌入精美模板，产出单文件自包含 HTML（Tailwind + Alpine via CDN，天生好分享）。
  2. 把产物 commit / push 到你 GitHub 仓库的 gh-pages 分支。
  3. 维护一个站点首页——你全部报告的倒序时间轴，超 30 天自动折叠。

安装

当前从源码安装：

git clone <this-repo> mdsite && cd mdsite
npm install          # 装依赖
npm link             # 或 npm install -g .  → 全局可用 mdsite 命令
mdsite --help

不想全局安装也可直接跑：node /path/to/mdsite/bin/mdsite.mjs <command>。

未来发布到 npm 后：npm i -g @tomczhang/mdsite（命令仍是 mdsite）。

认证（只需一次）

mdsite 用你自己的 GitHub 凭证操作你自己的 repo。不需要 SSH key，也不需要配 GitHub Action。 按推荐程度：

方式 说明
gh auth login（推荐） 复用 GitHub CLI 登录，token 不落任何文件
Fine-grained PAT（次之） 仅授权 pages 仓库，权限给 Contents / Pages / Administration 读写，然后 export GITHUB_TOKEN=…
Classic PAT（兜底 ⚠️） 勾 repo scope，但授予全账号读写权限，泄露影响面大

token 绝不会被写入 .git/config、日志或任何文件——只在推送时经子进程环境临时注入。

核心流程

# 1) 初始化：建/复用你的 GitHub repo + 开 gh-pages Pages
mdsite init                      # 默认 repo = <你>/pages
mdsite init --repo <你>/my-pages # 指定仓库

# 2) 发布一篇报告
mdsite publish notes.md --title "周报" --category report --summary "本周进展"
mdsite publish page.html --title "看板" --category dashboard --summary "指标"
# → 输出真实链接：https://<你>.github.io/<repo>/report/<日期>/<slug>.html
  • 输入 .md 会转成 HTML 正文；.html 直通（适合已产出的富交互页面）。
  • --category 任意 kebab-case（report / spec / review / dashboard / changelog…）。
  • 站点根 https://<你>.github.io/<repo>/ 是你全部报告的时间轴，超 30 天默认折叠。

文档形态（模板）

发布时用 --template <type> 选模板：

type 形态
report（默认） 标准报告页，单栏正文 + 标题 + 摘要
doc 三栏文档布局：左侧章节导航 + 内容 + 右侧 TOC
dashboard 仪表盘式布局

特殊：输入是完整 HTML（或带 --raw）时不套模板，原样发布。

辅助命令

mdsite doctor                  # 体检：凭证 / 工作区 / 配置
mdsite serve                   # 本地预览工作区
mdsite template list           # 查看可用模板（* = 已被本地覆盖）
mdsite template eject report   # 拷内置模板到 ~/.mdsite/templates/ 自定义

自定义模板

mdsite template eject <type> 把内置模板拷到 ~/.mdsite/templates/，编辑后即生效——用户层同名文件会覆盖内置默认。也可在 mdsite.yml 的 templates.<type> 把某 type 映射到任意文件名。

开发

npm test            # vitest 单元测试
npm run test:e2e    # Playwright 模板截图测试（前端 / 模板改动必跑）
