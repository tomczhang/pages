doc 模板（三栏版）示例

三栏满宽:左章节导航 + 中内容 + 右本页目录,对齐之前的 SPA 版式。

背景

doc 模板现在是三栏满宽:左侧章节导航、中间内容、右侧本页目录。

安装

npm i -g @tomczhang/mdsite

前置条件

node ≥ 20。

用法

mdsite publish guide.md --template doc ...

选项

--template、--summary 等。

排版能力

支持语义 callout、表格、代码、kbd。

💡提示

长文档用 doc,看板用 dashboard,单页结论用 report。

小结

左导航跳章节、右目录看位置,空间用满。
